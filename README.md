# 학원노트

혜원이 학원 시간표 · 준비물 체크 · 숙제 · 학원비를 한 곳에서 관리하는 **설치형 웹앱(PWA)** 입니다.
GitHub Pages에 올리면 폰 홈 화면에 아이콘으로 설치되고, 주소창 없는 전체화면으로 열리고, 인터넷이 없어도 켜집니다.

**오늘 화면에 학원과 차량이 시간 순서대로 함께 표시됩니다.**
예) 수요일 → 유치원 차량 16:00 → 피아노 16:00 → 영어 17:00 → 잉글리시아이 차량 17:50

> **확인해 주세요**
> - **탑승 / 하원 구분**은 제가 추측해서 넣었습니다. 다르면 차량을 눌러 **구분**을 바꿔 주세요.
> - 월·수·목은 **16:00에 유치원 차량을 타고 피아노로 가는** 흐름으로 표시됩니다.
>   같은 시각이면 차량이 수업보다 위에 놓입니다.
> - **목요일**은 피아노가 16:30에 끝나는데 벨칸토 차량이 17:30으로 되어 있습니다.
>   실제 하원 시각이 다르면 이동·차량에서 고쳐 주세요.
> - **준비물은 임시로 넣었습니다** (영어: 교재·숙제 노트 / 피아노: 악보·레슨 노트 / 한글: 글쓰기 공책·필통).
>   실제로 챙기는 물건으로 앱에서 바로 고쳐 주세요.

## 1단계 — GitHub에 올리기 (5분, 터미널 없이)

1. [github.com/new](https://github.com/new) 접속
2. **Repository name**에 `hakwon-note` 입력
3. **Public** 선택 → **Create repository**
4. 다음 화면의 **uploading an existing file** 클릭
5. 압축을 푼 폴더 안의 **모든 항목을 드래그**해서 올립니다
   - `index.html`
   - `manifest.webmanifest`
   - `sw.js`
   - `README.md`
   - `icons` 폴더 (안에 png 4개)
6. 아래 **Commit changes** 클릭

> `icons` 폴더가 드래그로 안 올라가면, 폴더를 열고 png 4개를 선택해서 올린 뒤
> 파일 이름 칸을 `icons/icon-192.png` 처럼 고쳐 주면 폴더가 자동으로 만들어집니다.

## 2단계 — GitHub Pages 켜기 (2분)

1. 저장소 상단 **Settings** → 왼쪽 메뉴 **Pages**
2. **Source**를 `Deploy from a branch`로
3. **Branch**를 `main` / `/ (root)` 로 선택 → **Save**
4. 1~2분 뒤 페이지 위쪽에 주소가 나옵니다

```
https://내아이디.github.io/hakwon-note/
```

이 주소는 **로그인 없이 누구나** 열 수 있습니다. 남편분께 링크만 보내면 됩니다.

## 3단계 — 폰에 앱으로 설치하기

**아이폰 (반드시 Safari에서)**

1. Safari로 위 주소 열기
2. 아래 **공유 버튼(↑)** → 메뉴를 내려 **홈 화면에 추가**
3. 이름이 `학원노트`로 들어와 있는지 확인 → **추가**

**안드로이드 (Chrome에서)**

1. Chrome으로 위 주소 열기
2. 오른쪽 위 **⋮** → **앱 설치** (또는 **홈 화면에 추가**)
3. **설치**

설치하고 나면 홈 화면 아이콘으로 열리고, **주소창이 사라지고**, 비행기 모드에서도 켜집니다.

## 폰에서 쓰는 법

| 하고 싶은 것 | 방법 |
| --- | --- |
| 준비물 체크 | 오늘 화면의 준비물 칩을 톡 누르거나, 준비물 탭에서 줄을 누름 |
| **전날 밤에 미리 챙기기** | 준비물 탭 오른쪽 위 **›** 를 눌러 **내일**로 이동 (최대 ±7일) |
| 화면 이동 | 하단 탭 또는 **좌우로 스와이프** |
| 할 일 추가 | 할 일 탭 아래 입력창에 적고 학원·날짜 고른 뒤 **+** |
| 할 일 수정·삭제 | 할 일 제목을 누름 |
| 학원 등록·수정 | 시간표 탭 오른쪽 위 **+**, 또는 시간표 블록·학원 목록을 누름 |
| **요일마다 시간이 다를 때** | 학원 수정 화면의 **요일마다 시간이 달라요** 스위치를 켜면 요일별로 따로 넣을 수 있어요 (한글학원이 이렇게 설정되어 있습니다) |
| **차량 추가·수정** | 시간표 탭 아래 **이동 · 차량**에서 추가하거나 눌러서 수정 |
| 학원비 납부 표시 | 학원비 탭에서 스위치를 켬 |
| 아이 이름 변경 | 오늘 화면 왼쪽 위 이름 동그라미 → 설정 |

오늘 일정이 다 끝난 저녁이면 상단 카드가 **내일 준비**로 자동 전환됩니다.

## 데이터는 어디에 저장되나요

**이 폰 안에만** 저장됩니다 (브라우저 저장소). 서버로 나가지 않고, 인터넷이 없어도 읽고 씁니다.

- 새 폰으로 옮기거나 남편 폰과 맞출 때는 **설정 → 백업 파일 내려받기**로 받은 JSON을
  상대 폰에서 **설정 → 백업 파일로 복원**하면 됩니다.
- 브라우저 데이터를 지우면 함께 지워지니, 한 달에 한 번쯤 백업을 받아 두세요.
- 두 사람이 실시간으로 같은 데이터를 보는 방식은 별도 서버가 필요합니다. 원하시면 다음에 붙여 드릴 수 있어요.

## 앱을 고쳤을 때

파일을 다시 올리면 GitHub Pages가 자동으로 갱신됩니다. 다만 설치된 앱은 이전 버전을 캐시하고 있어서,
**`sw.js` 안의 `hakwon-note-v6`를 `v7`로 바꿔** 함께 올려야 폰에서 새 버전을 받아갑니다.

## 파일 구성

```
index.html            앱 전체 (화면 · 저장 · 디자인)
manifest.webmanifest  앱 이름 · 아이콘 · 전체화면 설정
sw.js                 오프라인 캐시
icons/                홈 화면 아이콘 (192 / 512 / 애플 / maskable)
```
